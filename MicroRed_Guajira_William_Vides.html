Supuestos y restricciones

Datos académicos de ejemplo. Los valores se usan para practicar algoritmos y no sustituyen mediciones del sitio, estudios de recurso, diseño eléctrico, cálculo estructural ni cotizaciones reales.
Restricciones:
• La batería permite usar el 80% de su capacidad nominal.
• El respaldo se limita a 4 horas equivalentes de potencia disponible en este modelo.
• Primero se atienden cargas esenciales.
• Si falta energía, las cargas flexibles se desconectan antes del respaldo.
Objetivo del proyecto:
Seleccionar una combinación que mantenga servicios fundamentales, alcance la cobertura deseada, tenga suficiente autonomía y reduzca la dependencia del respaldo.

🧠 Foco lógico inicial

Recorrer: revisar cada carga y sumar potencia × horas.

Clasificar: separar esenciales de flexibles.

Generar: calcular energía solar y eólica.

Balancear: atender demanda con generación, batería y respaldo.

Comparar: calcular cobertura, autonomía y costo.

Decidir: escoger la alternativa más adecuada según la meta.

🧩 Pseudocódigo

INICIO
  leer hogares, población, horas_sol, factor_viento
  leer batería y respaldo

  demanda = 0
  esencial = 0

  PARA cada carga seleccionada
      consumo = potencia * horas
      demanda = demanda + consumo

      SI carga es esencial
          esencial = esencial + consumo
      FIN SI
  FIN PARA

  solar = capacidad_solar * horas_sol * rendimiento
  eólica = capacidad_eólica * 24 * factor_viento * rendimiento

  energía_renovable = solar + eólica
  cubrir primero la demanda con renovables

  SI falta energía
      usar batería
  FIN SI

  SI todavía falta energía
      usar respaldo
  FIN SI

  cobertura = energía_atendida / demanda
  autonomía = batería_utilizable / consumo_esencial

  mostrar resultados
FIN
